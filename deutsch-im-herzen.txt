مشخصات اولیه پروژه — پلتفرم آموزش زبان آلمانی
1. ایده کلی پروژه

این پروژه یک پلتفرم وب مدرن برای یادگیری زبان آلمانی است که تمرکز اصلی آن در نسخه اولیه روی زبان‌آموزان بزرگسال و نوجوان، به‌خصوص افرادی است که قصد یادگیری آلمانی برای زندگی، تحصیل، کار، Ausbildung و مهاجرت به آلمان را دارند.

هدف پروژه صرفاً ارائه یک دوره آموزشی یا یک دیکشنری ساده نیست؛ بلکه قرار است به مرور به یک Personalized German Learning Platform تبدیل شود؛ یعنی سیستم بتواند سطح، کلمات یادگرفته‌شده، اشتباهات، نقاط ضعف، فعالیت‌ها و پیشرفت هر کاربر را ذخیره و بر اساس آن مسیر یادگیری شخصی‌سازی‌شده ایجاد کند.

محصول از ابتدا با رویکرد Scalable Product طراحی می‌شود تا در آینده قابلیت‌هایی مانند دوره‌های ویدیویی، AI Tutor، تمرین‌های هوشمند، سیستم اشتراک، پرداخت، محتوای تخصصی Ausbildung و حتی مسیر جداگانه آموزش کودکان به آن اضافه شود.

2. هدف MVP

هدف MVP این نیست که تمام قابلیت‌های یک پلتفرم آموزش زبان را پیاده‌سازی کند.

هدف این است که یک هسته واقعی و قابل استفاده ایجاد شود که شامل چهار بخش اصلی باشد:

Dictionary
Learning
Practice
User Progress

کاربر بتواند:

حساب کاربری ایجاد کند.
وارد سیستم شود.
کلمات آلمانی را جستجو کند.
معنی و اطلاعات کامل کلمات را ببیند.
کلمات را به لیست یادگیری خود اضافه کند.
دروس و محتوای آموزشی را مطالعه کند.
تمرین‌های مختلف انجام دهد.
نتیجه تمرین‌ها ذخیره شود.
پیشرفت خود را مشاهده کند.
سیستم بر اساس عملکرد او پیشنهاد مرور و تمرین ارائه دهد.
3. مخاطب اصلی MVP

تمرکز نسخه اول روی بزرگسالان و زبان‌آموزان آلمانی است.

مخاطبان اصلی:

زبان‌آموزان A1 تا B2
افرادی که برای مهاجرت به آلمان آماده می‌شوند
متقاضیان Ausbildung
دانشجویان
افرادی که قصد کار در آلمان دارند
افرادی که می‌خواهند German واقعی و کاربردی یاد بگیرند

در MVP تمرکز اصلی روی A1–B2 خواهد بود، اما ساختار دیتابیس و محتوا باید طوری باشد که C1 و C2 نیز در آینده قابل اضافه شدن باشند.

23. اصل مهم توسعه پروژه

این پروژه قرار نیست صرفاً یک پروژه Frontend باشد که بعداً یک Backend به آن وصل کنیم.

از ابتدا:

Frontend
       ↕
REST API
       ↕
Backend
       ↕
Business Logic
       ↕
PostgreSQL

طراحی می‌شود.

بنابراین هر چیزی که در مسیر Backend یاد می‌گیری، باید تا حد امکان در همین پروژه پیاده‌سازی شود.

مثلاً:

یادگیری REST API
        ↓
ساخت Dictionary API

یادگیری SQL
        ↓
طراحی Word Database

یادگیری Authentication
        ↓
ساخت User System

یادگیری Authorization
        ↓
Admin / User Roles

یادگیری Validation
        ↓
Exercise Submission Validation

یادگیری Transactions
        ↓
ثبت نتیجه تمرین + Progress

یادگیری Testing
        ↓
تست APIها

یادگیری Docker
        ↓
Containerize Backend + PostgreSQL

یادگیری Deployment
        ↓
Deploy Production

در نتیجه پروژه همزمان سه نقش خواهد داشت:

1. پروژه یادگیری

برای یادگیری واقعی Backend.

2. پروژه Portfolio

برای نشان دادن مهارت‌های حرفه‌ای Frontend + Backend.

3. پروژه Product

با معماری‌ای که بتواند در آینده به یک محصول واقعی و درآمدزا تبدیل شود.
